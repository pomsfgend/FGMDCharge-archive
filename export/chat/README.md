# Проекты Романа (pomsfgend) — что где лежит
Собрано Фейт 14.10.2026. Сводки агентов лежат в `docs/`.

## Папки
- `cube-firmware-ref/FGMDCharge-FD-ROUND-V2`: прошивка кубика-обманки GB/T на ESP32-C3, линия 2.8.x (последняя 2.8.18-beta). Поддерживает 4 протокола станций, в `original/` лежит дамп заводской прошивки. Старые сборки не скопированы, они лежат на GitHub.
- `cube-firmware-ref/FGMDCharge-S3`: прошивка кубика на ESP32-S3, линия 3.0.0. Ветка `beta/hv-feedback-s3` с портом заводского регулятора «батареи» (`main/hv_fb.c`) есть только здесь, на GitHub её нет. На железе не проверялась.
- `cube-firmware-ref/review-fixes-*`: патчи и сборка исправлений по ревью.
- `cube-s3`: сборка кубика на S3 со старой платой: `BUILD_GUIDE.md`, фото точек пайки, схема `wiring.png`, готовый бинарник беты.
- `smart-ebike`: умный электровел на ESP32-S3 (свет, поворотники, BMS, дисплей, контактор). Документы в `docs/`, прошивка PlatformIO в `firmware/`.
- `charger-gbt`: будущая быстрая зарядка велосипеда на 100 А от станций GB/T, черновик.
- `docs/`:
  - `FATE_summary_cube_ebike.md`: общая сводка Фейт по кубику и велику, в §12 план для кода;
  - `BUILD_GUIDE_cube_s3.md`: руководство по сборке кубика;
  - `ORLA_battery_bms.md` и `balancer_tl431.png`: батарея, JBD, протокол UART, балансир (Орла);
  - `pins_v2_summer.h`: актуальная раскладка выводов велосипеда (Summer, подтверждена BoB);
  - `Votol_EM50-4.pdf`: документация контроллера (версия 60 В, CAN, UART на контактах 10 и 11).

## Итог на 14.10.2026
1. Кубик. Старая плата C3 сгорела: пробились стабилизаторы, 12 В попали на 3,3 В. По дампу разобрали, что делала заводская прошивка: на время проверки станцией выдавала «батарею» 240 В через свой повышающий преобразователь. Этот регулятор перенесён в бету S3. Решено поставить S3 на старую плату вместо C3. Ждём новую ESP, первая пришла подменой.
2. Велосипед. Раскладка: JBD A на 17/18, JBD B на 41/42 (обе через развязку ADuM1201), Votol на 4/5 (10 TX → GPIO5, 11 RX → GPIO4, вход защищён). Консоль идёт через родной USB. Тормоз берём из байта 20, бит 4, в ответе Votol. GPIO14 и 15 в запасе. Votol только читаем.
3. Батарея. Две сборки 18S1P по 50 Ач в параллель, у каждой своя JBD SP24S004. Разбег ячеек до 0,4 В, выравнивать будем вручную блоком питания (подробности у Орлы).
4. Зарядка на 100 А: при 3,55–3,60 В на любой ячейке снижать ток до минимума станции, на 3,65 В останавливать.
5. Telegram-группа оформлена, бот @Fategrokbot отвечает на вопросы по проектам.
