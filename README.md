# Архив FGMDCharge

Старые прошивки, исходники и выгрузки. На сайт они не влезают, поэтому лежат здесь.

- `firmware/` — bin всех сохранённых версий
- `archive/sources/` — исходники старых сборок
- `export/versions/` — исходники по версиям
- `export/chat/` — сохранённые тексты

Полный архив одним файлом:
https://github.com/pomsfgend/FGMDCharge-archive/releases/download/full/CUBE_FULL.zip

Текущая прошивка для записи с сайта — 3.0.91. Она есть и здесь.
